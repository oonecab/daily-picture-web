# 浏览器状态与生命周期

状态：CURRENT；基线版本：1.1.1；生效日期：2026-10-20；维护角色：项目维护者。

权威范围：[public/app.js](../../public/app.js) 和 [public/sw.js](../../public/sw.js)。短时交互证据见 [VERIFICATION.md](../../VERIFICATION.md)，未验证范围见 [问题 003](../../issues/003-validation-gaps.md)。

## DP-LOCAL：收藏与离线

localStorage 使用 `daily-picture-v1` 前缀，保存收藏元数据、偏好与上次归档。最多 200 个收藏，同源多标签页通过 storage 事件同步。没有账号、跨设备同步或原生 UWP 数据导入；清理网站数据会丢失这些记录。不同主机名/端口构成不同来源，不应宣称更换端口后收藏自动迁移。

Service Worker 缓存应用外壳、归档、访问过的图片。离线只能使用之前成功缓存且尚未淘汰的资源；首次访问仍需服务与上游可用。图片收藏不是永久备份。安装入口由浏览器事件决定，操作系统安装并未验证。

1.2.0 外壳缓存为 `daily-picture-v1-shell-1.2.0`，激活后淘汰旧外壳；保留 `daily-picture-v1-data`、`daily-picture-v1-images` 与原 localStorage 键。归档窗口升级由服务端 DP-CACHE 处理，离线时仍可浏览旧数量。界面文案为“最近十五日”，计数始终取实际列表长度。

外壳优先网络，等待上限 5 秒；网络异常、超时及 HTTP 5xx 回退已缓存资源，导航还可回退缓存首页；4xx 保持服务器原响应。成功响应更新外壳缓存。没有可回退外壳时返回 503。

图片写入串行处理，按缓存插入顺序淘汰，目标为最多 80 个尺寸版本、64 MiB。新响应以 Blob 实际长度计量并记录 Content-Length；旧缓存优先读取原长度头，缺失或无效时读取 Blob 长度。写入前清理超预算条目，旧缓存渐进整理；读取命中不改变插入顺序。浏览器自身配额可能更小：首次 `QuotaExceededError` 再淘汰至少 8 个旧项或剩余项的四分之一（不足时删除现存旧项），仅重试一次。仍失败时在线响应继续返回，通过消息提示页面离线保存不可用，每页最多提示一次；不清除收藏、偏好或地区归档。64 MiB 为图片响应体预算，不包含浏览器存储元数据。

切图只更新选中属性，保留已有缩略图节点和键盘焦点；收藏标记原位更新。列表/模式变化或空列表加载状态变化时重建，能匹配原图片时恢复缩略图焦点。横向列表的已有滚动位置在普通切图时保留。

## DP-LIFECYCLE：请求与计时器

切换市场时取消旧归档请求，并用 generation 检查忽略迟到响应。前端归档请求超时 25 秒，图片下载请求超时 30 秒；这与服务端上游共享 20 秒预算是不同层次。

可见且启用自动刷新时每 60 秒检查距上次检查是否达到一小时；重新可见或恢复联网时按条件补查。幻灯片每 8 秒切换；手动切换、弹窗、隐藏页面等会停止。隐藏时停止刷新检查；`pagehide` 停计时、取消归档并回收下载 Blob URL。下载 URL 也会在约 60 秒后回收。

浏览器在页面关闭后不运行定时更新，不调用 Windows 壁纸/锁屏/磁贴 API。1.2.0 的中国区索引采集由仍在运行的 Node 服务承担，详见 [DP-HISTORY-STORE](history.md)。实际等待满一小时和浏览器后台调度差异尚未验证；不能以代码中存在计时器或 8 秒幻灯片成功代替这一验收。

## 全屏视图的临时状态（2026-10-19 修复）

浏览器优先使用标准或 WebKit 前缀 Fullscreen API；接口缺失、明确禁用或请求拒绝时，仍使用固定定位的网页视口模式。两种模式均保持图片比例，使用动态视口高度与安全区域内边距布置按钮。回退模式的覆盖范围为网页可用视口；浏览器工具栏、地址栏与系统状态栏不受页面控制。

进入时记录页面滚动位置、焦点和背景元素原有 inert 状态，锁定背景滚动，并将键盘焦点约束在图片操作区。关闭按钮、F、Esc 或浏览器退出原生全屏后恢复这些临时状态。打开详情/下载等弹窗前先退出视图；列表变空时退出，避免隐藏唯一退出按钮。迟到的原生请求也会在视图已关闭时退出。以上状态仅保存在页面内存，不写入收藏、偏好或缓存；现有 DP-LOCAL 存储格式和 DP-LIFECYCLE 计时规则不变。

## 1.6.0 多地区历史兼容

localStorage 键保持 daily-picture-v1；收藏身份为 market+date+id，防止同 ID 的其他地区记录被误取消。所有既有中国收藏保留，历史图片 URL 省略 market 时仍为中国。Service Worker 外壳升级至 shell-1.6.0，数据及图片缓存名称不变，总预算不按地区倍增。

历史地区与顶部地区联动，历史模式中切地区保留该模式；当原月份不在新地区目录时选择该区最新月。目录/月请求验证返回 market，切区、切月和切标签均中止旧请求并丢弃迟到响应。原生年月控件、键盘焦点、44px 最小触控高度及小屏无横向溢出均需验收。

1.6.1 仅将外壳缓存升级至 shell-1.6.1；历史工具栏改为与主图对齐的独立选择器，移除重复视觉标题但保留动态无障碍名称，状态文案展示本月收录数量。已有收藏、偏好及 data/images/history 缓存继续保留。

## 1.6.2 近期图片与离线兼容

近期主图/缩略图使用匿名 CORS 直连入口，错误后仅回退同 ID/尺寸的本站代理一次。主图直连最多等待 12 秒；下载在总计 30 秒内给直连 10 秒，失败后使用剩余预算回退；下载与主图拒绝明显占位小图。历史已有直连规则保持。Service Worker 把近期 URL 的 direct/download 参数从缓存键中移除，沿用升级前的图片键和 80 项/64 MiB 预算，直连成功图片也可离线使用；不缓存 opaque 响应。外壳升至 shell-1.6.2，收藏、偏好和 data/images/history 缓存名称不变。

直连图片写入离线缓存前，在支持 createImageBitmap 的浏览器中校验解码和最小尺寸 320×180；占位小图或不可解码内容不进入共用缓存，避免遮蔽代理回退。
