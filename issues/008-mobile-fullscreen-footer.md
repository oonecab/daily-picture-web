# 008：手机全屏回退与页脚图标

- 状态：resolved（本地）；日期：2026-10-19（Asia/Shanghai）。
- 风险档位：普通修复。范围限于浏览器看图交互和页脚展示，可恢复相关源码回退。
- 用户反馈：手机点击全屏仅提示不支持；页脚箭头显示成彩色方块，与页面风格不一致。

## 原因与验收设计

`fullscreen()` 只有标准 Fullscreen API 成功路径，没有网页内回退；页脚使用 Unicode 箭头，实际字形取决于设备字体。全屏改为优先使用浏览器接口，缺失、禁用或拒绝时仍可在网页可用视口欣赏完整图片。浏览器地址栏和系统状态栏由浏览器控制。

先增加可执行回归，证明旧实现无法进入回退模式。验收覆盖进入/退出、浏览器主动退出原生全屏、拒绝/前缀接口、Esc/Tab、滚动与焦点恢复、详情弹窗、收藏移除最后一项和空列表。真实浏览器检查手机竖屏/横屏、页脚、桌面原生全屏及控制按钮可达性。

页脚使用现有 SVG 图标系统，外部链接用细线外链图标，“关于”用信息图标；调整对齐与触摸区域。服务 API、数据格式、存储键、核心技术栈和环境配置没有变化。

## 文档影响

更新 README 的全屏使用边界、浏览器状态文档的临时视图生命周期，以及测试基线。无需新增技术栈索引、API 契约或部署记录。本次任务为本地修复与验证。
