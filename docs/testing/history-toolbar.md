# 历史工具栏验收

状态：进行中；版本：1.6.1；关联：[问题 024](../../issues/024-history-toolbar.md)。

设计验证：原图中 740px 居中卡片具有两层容器、重复地区标题和装饰副标题。目标为与主图左边缘对齐的紧凑筛选组、右侧记录数、细分隔线；手机端三个选择器保持一行，状态单独换行。实际验证桌面与 320/390px、选择器有效点击高度、键盘焦点、错误信息完整显示、月份切换和收藏保留。

本次为视觉/文案调整，不为 CSS 属性新增实现镜像测试；既有浏览器行为及完整回归保留，视觉变化通过实际浏览器核对。

本地验证：Windows / Node.js 24.14.0 全量 152/152，通过；语法 19 文件、研究快照 238 文件/432 链接和严格治理校验通过。Chrome 1920px 视口下工具栏高 63px、筛选组宽 420px，左边缘与主图一致；320/390px 下工具栏宽 288/351px、高约 88.7px，三个选择器各高 44px，无横向溢出。640px 和 320px 长状态信息自然换行且无溢出。方向键把中国切换为美国，Tab 移至年份并显示外侧 2px 焦点；2010-01 正确显示 31 条。强制颜色模式保留可见边框与焦点。移动端为桌面 Chrome 视口模拟，不等于真实手机硬件测试。
