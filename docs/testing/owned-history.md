## 测试设计

- 真实可解码 3840×2160 JPEG 生成独立 640×360、1920×1080 JPEG；原图逐字节保留，缩略图字节显著减小，不放大小图。
- HTML、结构完整但不可解码 JPEG、过大输入/像素、损坏存储被拒绝；输出不成为可用图片；并发受限，失败不覆盖原索引。
- 月浏览不触发第三方网络；未导入与缺失图片有明确反馈；同 ID 合并保留来源和本地媒体状态，ID 变化不复用旧图。
- 缩略图 URL、预览 URL、原图下载 URL 分离，只有视野内两张缩略图可并发，切月/切图后迟到结果不覆盖。
- 导入断点续跑、双来源缺档/部分失败、原图失败保留元数据、重复采集不丢历史；Actions 来源仅 Bing，数据分支不保存凭据。
- 本地服务重启后在上游断网情况下仍可读已导入月份及三种图片；端点拒绝未知 size、路径/URL 注入和未索引 ID。
