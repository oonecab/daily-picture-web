# 简洁页脚验收

日期：2026-10-21 Asia/Shanghai；版本：1.4.1。关联[问题 020](../../issues/020-compact-footer.md)、[计划 016](../../plans/016-compact-footer.md)、[里程碑 016](../../milestones/016-compact-footer.md)。

## 范围与基线

只调整首页页脚及来源声明的位置说明，历史索引、图片、下载和每日采集逻辑不变。旧线上页面实测 `footer .archive-credit` 为 2 个；“关于”已有两个正确的项目链接。因此“页脚没有来源大卡片”的新验收条件在旧页面不成立。

## 验证设计

- 既有自动测试、JavaScript 语法、研究资料完整性和治理校验。
- 桌面与 390px 窄屏：页脚没有大卡片、没有横向溢出，Bing/源码/关于仍可用；“关于”键盘打开、关闭及焦点恢复，两份来源链接保留。
- 公网：版本、静态资源摘要及实际页面对应新发布；抽查历史月及保存的图片读取。保留原图库链接和上一发布，核对服务配置不变。

## 执行结果

- `npm run check`：13 个文件语法通过；`npm test`：113/113 通过，0 跳过。
- 研究资料校验：238 个文件、432 个本地链接通过；治理校验及 `git diff --check` 通过。变更文件敏感内容定向扫描无命中；未安装 Gitleaks，定向扫描不等同于该工具扫描。
- 实际浏览器：1440×1000 桌面和 390×844 手机视口均无横向溢出；来源卡片为 0，页脚高度分别约 77px / 112px。手机页脚链接/按钮高度 44px。
- “关于”：两份来源链接保持正确目标及 `noopener noreferrer`；Enter 打开、Esc 关闭后焦点回到触发按钮。手机点击打开/关闭正常，正文及长链接无横向溢出。截图已实际检查，保存在私有验收记录。

上线与公网核对待执行。真实手机触摸、Safari 和长期每日调度不在此次界面调整的验证范围。
