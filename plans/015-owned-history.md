# 计划 015：自有历史图库

关联：[问题](../issues/019-owned-history.md)、[测试](../docs/testing/owned-history.md)、[里程碑](../milestones/015-owned-history.md)。

1. 先写失败回归；实现受限解码、真正缩略图/预览与原图分流，保留懒加载和取消行为。
2. 分离第三方导入与本地浏览；提供可续跑、逐项记录失败的导入工具，原图独立持久保存。
3. 添加 GitHub Actions 从 Bing 获取近期窗口、按月去重并保存到 codex/wallpaper-data 分支；服务后台同步自有索引并保存图片，不在访客请求中读取第三方。
4. 真实样本、完整导入、正常/失败/重复执行测试、桌面/窄屏网络验证；同步权威文档。
5. 沿用已授权的检查、提交、推送和发布流程；核对远端身份、发布摘要、索引保留和 Actions 实际运行。

导入在隔离目录执行，完成后迁移到持久目录；不让两个进程同时写生产历史索引。限制并发、请求时限和图片像素/字节数。失败图片保留索引及失败原因，允许独立重试。未导入月份与缺失日期如实展示。原图库不在源码 Git 历史内保存大体积图片。
