## 浏览器验收

页面通过本地服务显示真实 Bing 中国市场图片。以 CDP 设置视口尺寸；在测试标签页将 gallery 的标准/前缀全屏方法暂时设为 undefined，验证真正的浏览器 DOM/CSS 回退路径；这些注入不会写入源码或持久化设置。

| 场景 | 已观察结果 |
| --- | --- |
| 393×852 竖屏、全屏 API 缺失 | 视图矩形为 x=0、y=0、393×852；图片 object-fit=contain；背景固定；关闭按钮 44×44；图片完整可见 |
| 852×393 横屏 | 视图矩形为 852×393；顶部退出与底部下载均在视口内；切换下一张成功 |
| 全屏打开图片详情 | 退出视图并解除滚动锁；对应图片详情弹窗正常打开 |
| 393px / 320px 页脚 | 页面 scrollWidth 等于视口宽度；三个链接/按钮高度均为 44px；细线 SVG 与文字对齐；关于弹窗可打开并关闭 |
| 1280×900 桌面原生全屏 | document.fullscreenElement 为 gallery；退出按钮显示正确；实际按 Esc 后恢复普通视图并解除滚动锁 |
| 触摸、焦点与动态视口 | CDP 触摸输入将 01/15 切换为 02/15；最后一个按钮按 Tab 回到幻灯片按钮；视口从高 852 缩到 700 后，视图同步为高 700，下载按钮仍可见 |
| 滚动与焦点恢复 | 在 scrollY=180 进入回退视图，退出后仍为 180，焦点回到全屏按钮 |
| 全屏移除最后一张收藏 | 在初始空收藏的本地来源临时收藏一张，再全屏移除；自动退出，解除滚动锁，焦点移到 gallery，收藏恢复为 0 |

实际截图已逐张查看，保存在本机忽略目录 `test-output/mobile-ui-20261019/`：`portrait-fullscreen.png`、`landscape-fullscreen.png`、`portrait-footer.png`、`small-footer.png`、`desktop-native-fullscreen.png`。此目录为本次本机验收附件，不是随 Git 分发的测试夹具。

## 范围与限制

这是 Chromium 浏览器的实际渲染与手机尺寸模拟，不是实体 iPhone 或 iOS WebKit 运行证明。WebKit 前缀接口由状态测试覆盖；刘海和底部手势区使用 CSS safe-area-inset，实体设备效果仍待手机复核。浏览器地址栏与系统状态栏属于浏览器控制区域。没有执行生产部署、系统安装或手机端实际下载。

全屏与页脚说明已同步 README、浏览器状态文档和测试基线。未改服务 API、核心栈、环境、收藏/偏好键和 Service Worker 缓存策略。静态资源继续按现有 network-first 外壳策略加载，联网重新打开页面后获得本次源码。
