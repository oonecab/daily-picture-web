用户授权从两个现有归档一次性导入历史数据并保留署名，之后维护自己的索引和图片，新增索引由 GitHub Actions 从 Bing 获取。优先解决历史缩略图传输原图及按需加载，完成可用性检查和测试。

采用独立持久图片目录、640 像素缩略图、1920 像素预览和原始 JPEG。图片经 Sharp 完整解码后发布；磁盘文件摘要和清单关联同一日期与图片 ID。导入工具显式访问第三方，网页浏览只读自有索引/媒体。后台同步本仓库 codex/wallpaper-data 分支的每日索引，并保存新增图片。Actions 只需当前仓库 contents:write，不持有服务器凭据。

文档影响：TECH、治理清单、README、第三方声明、历史规则/契约、架构、环境/发布和测试基线。增加 Sharp 锁定依赖及 npm ci 安装步骤。保留已有月度 schema、收藏和原始索引；新增存储不随缓存淘汰。发布保留旧版本和数据备份，回滚不删除新图库。

验收及实际导入缺口、发布证据待执行后追加，不能把索引存在当成图片已备份。
