# 多地区历史验收

状态：已完成并上线；日期：2026-10-26；关联：[问题 023](../../issues/023-multi-region-history.md)。下文按阶段保留调查记录，最终口径以文末验收为准。

先行回归设计：

- 六地区独立月份、日期时区和媒体目录；同日记录、同步状态互不覆盖。
- 中国区现有 schemaVersion=1 文件、受保护副本、收藏和无 market 的旧请求保持可读。
- 固定归档源：市场/日期/ID 必须匹配索引；拒绝任意主机、伪造来源、重定向、错误类型、占位图和超限文件。
- 原图/预览按需获取，仅临时缓存；导入只生成缩略图和清单，磁盘余量不足则停止，恢复不重复下载已有缩略图。
- 多地区采集按地区独立报告失败；某地区失败不阻断其他地区，不把陈旧索引描述为成功更新。
- 地区切换、年月切换、晚到响应、收藏下载路由和离线缓存键；移动端无横向溢出，键盘焦点可见。
- Windows 慢连接测试使用可控响应背压，仍验证共享缓冲、占用预算、断连清理和超时。

2026-10-26 本地证据：

最终检查发现地区标签相同不代表上游地区正确：大陆服务器直接请求 www.bing.com 的海外每日索引，会将部分近期历史覆盖为 ZH-CN ID；GitHub Actions 对应文件中的地区 ID 正确。固定 global.bing.com 在同一服务器返回正确日本/英国记录。增加上游响应、近期缓存、入库和旧错误行修复的地区一致性规则；两项回归先失败，修复后 Windows 152/152 通过。早期“同步状态正常”只证明同步完成，不再作为完整地区正确性验收；最终复核逐条检查每日 ID 的地区后缀并修复受影响月份。
