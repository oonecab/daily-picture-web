# 023：多地区历史与紧凑筛选栏

状态：进行中；日期：2026-10-26；目标版本：1.6.0。

用户授权实现、验证、提交推送和部署。重要变更：历史数据隔离、固定归档图片来源、后台采集、公开 API 和生产发布。

范围：中国现有历史保持兼容；美国从 2010-01，英国、日本、德国、法国从 2024-04 开始。仅长期保存索引和缩略图，保留现有受保护副本；大图按需读取并共享 256 MiB 缓存。海外归档下载经本站校验后返回，不要求客户端直接访问归档源。历史栏收窄，支持地区、年月选择和状态提示。

边界：不把摄影作品纳入 MIT 授权，不接受用户提供的上游 URL，不清理现有图库或收藏，不复制整库原图到生产盘。导入必须隔离、可恢复，并在磁盘余量不足 10 GiB 时暂停。
