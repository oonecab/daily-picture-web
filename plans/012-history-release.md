# 012：历史壁纸发布计划

状态：执行中；关联 [问题 016](../issues/016-history-release.md)、[验收](../docs/testing/history-release.md)。

1. 审查历史索引、异步图片、API、离线和持久化边界；针对发现问题先加失败回归并修正，同步规则。
2. 执行本地完整检查、审查候选文件与敏感信息；以指定作者和提交者提交、普通推送并核对远端及 GitHub 账号关联。
3. 从已推送提交打包，生成文件摘要；上传独立版本目录，在服务器以服务账户执行语法和回归。保留原配置、旧版本及索引备份，验证持久目录写权限。
4. 原子切换并重启。验证健康、HTTPS 资源摘要、进程目录、浏览器历史年月/渐进加载/原图下载；检查自动启动采集与磁盘记录，重启后复核索引及历史内容仍在。
5. 记录实际结果与边界，推送验收文档，核对最终 Git 状态及线上运行文件与最终 HEAD 一致。

任何激活后的启动、健康或关键功能失败，使用保存的旧目标原子回滚并检查旧资源与健康；持久索引不删除。生产不注入上游失败或容量耗尽；异常分支在隔离回归中验证。
