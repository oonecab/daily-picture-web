# 里程碑

<!-- project-governance:managed:start -->
里程碑用于冻结一组内聚范围及其可观察的验收条件。

- 在每项必要条件均有经过检查的证据前，不得标记完成。
- 关联组成该里程碑的问题单、计划、测试设计、决策记录与发布证据。
- 完成证据必须说明代码、测试与权威文档是否一致；三者任一缺失均不得视为完成。
- 显式记录延期工作，不得静默缩减已约定范围。
- 创建新里程碑时复制 `_template.md`。复制后删除两行 `project-governance:managed` 标记；实际里程碑全文由项目自主管理。
<!-- project-governance:managed:end -->
