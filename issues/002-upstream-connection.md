# 002：间歇性上游连接失败根因未定

- 状态：开放；严重度：影响首次/强制刷新可用性，可回退时有降级提示。
- 发现日期：2026-10-17；依据：[原验证记录](../VERIFICATION.md)。
- 已观察：部分早期并发调用 502，日志 `fetch failed`，已缓存市场返回 stale；后续多轮恢复正常。
- 未确定：具体网络、代理、服务端或连接原因；早期没有底层原因记录，不能从后续成功倒推根因。

当前缓解见 [DP-RETRY / DP-CACHE](../docs/rules/cache.md)：最多一次重试、共享时限、旧数据回退和原因日志。回归测试验证了这些机制，**问题仍未关闭**。

后续在再次出现时保留时间、市场、HTTP 状态、底层 error.cause、请求数和缓存状态，避免记录秘密或无关完整载荷。区分可重复本地问题、上游变化与暂时连接失败，再提出修复及故障回归。没有复现时记录“未复现”，不能写“根因已修复”。

文档影响：任何重试预算、错误码或回退行为变化须同步缓存规则、Bing 契约、用户说明及测试设计。
