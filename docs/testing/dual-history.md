## 2026-10-21 实施与本次验收

新增 11 项来源测试在旧实现上全部失败（2018 下限、双源合并、旧索引补源、下载回退及来源安全）；新增 2 项 UI 测试在旧实现失败（实际尺寸与新来源详情）。复查新增 3 项边界，其中冷却期错误提示、混合候选临时错误分类在修改前失败，已修复；更换每日 ID 不继承旧变体通过。

当前 `npm run check` 通过，`npm test` **91/91** 通过。资料校验 238 个文件、432 个本地链接无失败；治理严格校验通过；diff 空白检查通过。README、页脚、第三方声明与规则/契约均标明两个项目、职责和分辨率边界。

浏览器使用 macOS 上的 ego-browser。因本机直连原始文件服务发生连接重置，隔离预览在已授权主机上使用独立临时数据目录与回环端口，通过 SSH 转发访问；真实读取上游，不复用生产历史目录。2018-09 返回 20 条；2018-09-30 主图真实解码及按钮下载均为 3840×2160 JPEG，下载事件成功，macOS sips 再次确认尺寸。桌面 1280×1050 的来源卡片并排、390×844 纵向排列，页面宽度 390 无横向溢出，Tab 可聚焦第二来源链接并显示焦点轮廓；已保存并查看截图。自动懒加载回归确认可见缩略图最多两张并发。

自动化下载之后对已自动关闭对话框的关闭点击曾失败；检查当前页面后继续验收，下载文件本身已成功。浏览器证据保存在忽略目录 `test-output/dual-history-20261021/`，不随源码发布。未验证所有历史日期的可用性、原生像素细节、Safari 或真实手机；旧图仍可能缺档或失效。

2018-09-11 首条记录同样真实解码为 3840×2160，详情链接正确指向 zxyongyo 项目。浏览器子树快照曾误用 CSS root，工具拒绝该观测参数；数据读取与界面操作已成功，后续改用普通快照。
