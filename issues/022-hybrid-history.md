# 022 — 历史图片分层保存与磁盘预算

状态：已完成；日期：2026-10-21；风险：重要变更。

用户授权长期保存索引和缩略图、预览及原图按需从 Bing 加载，所有服务端临时图片缓存共用 256 MiB；检查全部历史链接，失效或无法确认的图片保留本站副本，其余原图完成本地备份校验后清理服务器文件。授权包含提交、推送与部署。

基线：2,962 张图片，原图 10,915,444,268 字节、预览 1,452,456,222 字节、缩略图 140,499,015 字节，98 个月索引约 2.74 MB。旧图存在 UHD 失效但历史 1920x1080 变体仍有效的情况，不能统一改写为 UHD。

验收要求：全量 GET 与完整 JPEG 解码；备份按清单逐文件 SHA-256 比对；未知/失败来源保留原图；迁移核对日期和 ID；共享缓存并发写入及重启均不超过预算；浏览、下载、跨域失败回退、每日缩略图采集及跨窗口重试覆盖。上线验证通过后执行精确文件清理；回滚代码与本地备份均保留。

文档影响：历史规则、API 契约、架构、缓存规则、README、第三方声明、部署与测试基线；无新依赖。涉及 CSP 固定 Bing 来源和持久化语义，必须同步测试和发布记录。关联 [计划](../plans/018-hybrid-history.md)、[测试](../docs/testing/hybrid-history.md)、[里程碑](../milestones/018-hybrid-history.md)。
