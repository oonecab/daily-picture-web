- 320×740：页面宽度等于 320；GitHub 链接和页脚内容保持在页面范围内。此次为浏览器移动视口模拟，不是实际手机触控测试。
- 地区切换到美国：15 张、`01 / 15`、实时同步状态与主图解码成功。
- GitHub 链接：检查 href / target / rel，并实际点击；新标签页加载 `https://github.com/oonecab/daily-picture-web`，标题为该仓库的 GitHub 页面，原应用保留。
- 外壳升级：在加载应用前，向隔离上下文预置旧外壳、数据和图片缓存探针及收藏/设置；新版激活后仅移除旧外壳，生成 `daily-picture-v1-shell-1.1.0`，两个数据缓存探针与 localStorage 均保留。此项验证缓存迁移，不声称覆盖所有浏览器的后台更新时机。
- 真实停服回退：工具的 Offline 模拟没有切断此轮 Service Worker 请求（仍返回 `hit`），不采信为断网证据。随后停止本次测试服务，并用独立 HTTP 请求确认 `ECONNREFUSED`；重载页面仍显示 15 项、已缓存主图和 2 个收藏，归档返回 `cache=browser-offline`、`stale=true`，界面显示离线提示。
- 在线检查未发现 console error / warn。停止测试服务造成的网络失败是预期故障注入，不归为正常在线结果。
