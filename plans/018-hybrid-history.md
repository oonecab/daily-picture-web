# 历史图片分层保存计划

状态：已完成；关联 [问题 022](../issues/022-hybrid-history.md)。

1. 记录当前版本与磁盘基线；全量检查 Bing 原图/预览，保留每项链接变体、结果、尺寸和摘要。完整图库备份到用户本机并校验摘要。
2. 先补回归：每日仅持久化缩略图、历史直接读取 Bing、失效副本回退、统一缓存预算与迁移拒绝未备份文件；确认旧实现失败。
3. 实现固定来源链接、缩略图采集、按需读取、浏览器跨域/旧收藏兼容和 256 MiB 统一缓存。同步规则、契约和说明。
4. 完成自动测试、浏览器与受控容量检查，审查差异及敏感内容；提交普通推送，核对身份与远端 SHA。
5. 上传不可变版本，维护窗口更新索引并激活，验证公网浏览/下载/采集。完成备份与链接检查的文件才允许清理；保留失效/未知副本、本地完整备份和旧代码用于恢复。

采用 web-engineering-playbook E43（2026-10-13）的分阶段减少复制建议、E53（2024-11-26）的过载验证建议与 E54（2025-09-26）的可回退迁移方法；这是本项目的工程应用，不是来源对本项目的验证结论。

执行结果（2026-10-21）：五步均完成。完整备份与全量链接检查通过后，先更新索引、激活 1.5.0 并验证公网，再暂停写入执行精确清理，恢复服务后核对全部日期/ID、保留媒体摘要、缓存预算和新一轮同步。备份、旧版本及配置保留；[验证记录](../docs/testing/hybrid-history.md) 区分自动测试、受控容量、真实浏览器和实际生产结果。
