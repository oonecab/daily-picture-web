## 事实与范围

现有历史仅覆盖 2024-04 起，来源声明占用年月选择区。用户明确要求同时使用 npanuhin/Bing-Wallpaper-Archive 与 zxyongyo/bing-daily-wallpaper，在网站底部和 README 清楚署名并美化展示。新仓库按月 JSON 可回溯至 2018-09，提供 Bing 链接；标为 4K 的 URL 不保证原生拍摄分辨率。

采用独立适配器、按月合并与原有懒加载；保留每日持久索引。以已授权的历史功能检查、提交、推送、部署流程交付。

required：TECH、README、THIRD_PARTY_NOTICES、历史规则/契约、架构、环境清单和本次四类记录。新增只读外部来源，环境变量不变，无技术栈变更或数据库迁移。DP-HISTORY 更新日期下限、来源优先级、同图回退和尺寸语义，由用户批准，2026-10-21 生效。

## 验收与回滚

2018-09 按月可浏览下载；两个来源同日去重，单源失败保留另一源，原每日索引无丢失；页脚和 README 均列明两项目及摄影版权；桌面/窄屏实测。schemaVersion 1 只增加可选字段，旧文件可读。保留部署前索引备份与上个不可变发布；发现索引丢失、下载或主流程回归时切回旧发布，数据恢复须先确认，避免覆盖新采集记录。
