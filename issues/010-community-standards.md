## 验收条件

- 社区文件位于 GitHub 支持的位置；内容完整，联系渠道真实，没有未填写的占位符。
- Issue 模板可填写设备/浏览器、复现过程、预期/实际结果和截图，并提示安全漏洞使用私密渠道。
- 贡献指南的启动、检查命令与 package.json 一致；既有规则通过链接引用。
- GitHub About 与私密漏洞报告设置实际生效，Community Standards 识别新增文件。
- 已登记检查、YAML 解析、文档链接和提交内容检查通过；普通推送后本地与远端提交一致。

## 风险与回滚

主要风险是虚构联系渠道、误导漏洞公开提交、重复规范漂移以及社区文件中的未填写字段。先核实管理权限和渠道，再发布。文档可通过后续 revert 提交回退；简介和网站的原值均为空，可在 About 恢复。私密漏洞报告按需在仓库设置撤销启用；若已收到报告，先处理现有报告再调整入口。应用无需迁移或重新部署。
