# 分层图库验证

状态：本地验证完成，备份与发布验证进行中；日期：2026-10-21；关联 [问题 022](../../issues/022-hybrid-history.md)。

测试设计：

- 全量历史链接：逐日期与 ID 检查实际 GET、JPEG 类型/大小/完整解码、Bing 旧变体回退；失败和无法确认均保留本地副本。
- 备份迁移：检查每个媒体清单与字节 SHA-256、日期/ID 不丢失；拒绝未备份、过期检查或 ID 不匹配的清理；操作可断点恢复。
- 采集：只新增缩略图，持久化索引与待补；旧快照不倒退，窗口外失败继续重试。
- 图片：缩略图持久读取；大图浏览器从固定 Bing 来源加载；跨域/网络异常通过本站按需读取；失效图走受保护副本；旧收藏仍解析当前索引。
- 缓存：每日精选与历史图片共用 256 MiB，串行预留后原子写入；并发、重启、超大文件、读写失败不突破上限，失败响应不入缓存。
- 前端：桌面/移动端按月、按需加载、下载、收藏、Service Worker 升级与离线边界。
- 发布：本地与服务端登记检查、公网健康、部署文件摘要、真实下载解码和每日同步证据；清理前后磁盘统计及保留副本逐项验证。

2026-10-21 本地执行：138 项 Node 测试全部通过；17 个脚本语法检查、238 份研究文件及 432 个本地链接检查、严格治理校验、git diff --check 均通过。先行回归证实旧实现每日保存两个大文件，而新要求为零。新增覆盖包括历史预览 12 秒回退与切图释放定时器、下载直连超时预留回退时间、占位图拒绝、缓存读写失败仍可在线读取、暂时故障与旧变体 404 混合时保留待补状态。定向变更文件敏感信息扫描无命中；本机未安装 Gitleaks，未将该扫描称为 Gitleaks 检查。

真实浏览器：2018-09 按月读取 20 条索引，预览为 1920×1080；点击下载得到 3840×2160 JPEG，Sharp 完整解码通过。缩略图位于视野外时不发起请求，滚动后取得真实 640×360 图片。测试页面绕过 Service Worker 并屏蔽两个 Bing 主机，下一张预览改走本站代理，原图下载成功；测试后恢复浏览器网络设置。390×844 移动视口的文档宽度为 390，无横向溢出，年月选择和主图已检查。

全量线上 GET 检查覆盖 2,962 张原图与预览，包含 UHD 到旧变体的回退，全部找到可完整解码的链接；其中 2,959 张满足释放条件。2021-11-17、2021-12-08、2021-12-26 的本站原图分别为 5008×2817、5606×3153、4205×2365，而 Bing 当前返回 3840×2160，三张保留本站原图和预览。检查证明当时可用，不能保证 Bing 永久保留原图。
