## 异常、限制及交付

首次当月归档请求发生一次上游连接失败，页面明确回退本地 15 条索引；之后手动刷新成功合并为 21 条。另一次 2024-04-24 旧图缩略请求发生上游连接失败，索引保留；稍后在页面选中该图，重试成功并解码为 3840×2160。上线不承诺外部归档永久可用，未逐张检查所有年份图片。服务端 JPEG 检查是结构与尺寸检查，完整解码和画面仅抽样验证。

一次浏览器批量资源读取超过工具的页面脚本等待时限；重载后改为带独立超时的并行读取，六个资源全部验证通过。服务器日志读回最初因时间字符串格式不兼容退出，修正读取脚本格式后完整复核通过；应用与生产配置未因此修改。这些失败不计为通过。

没有实际连续等待一小时或多日；小时重调度、失败再调度、停止及跨日累计依赖隔离回归，线上已验证两次启动自动采集、落盘与重启保留。窄屏使用 Chromium 模拟，未验证实体手机/Safari。

本机可复核证据位于 Git 忽略的 `test-output/history-release-20261021/`，包含 tests.txt、source-scan.json、browser-before.json、browser-upgrade.json、history-desktop.json、public-resources.json、download.json、mobile.json、post-restart-browser.json、recovered-image.json、截图及实际下载。生产读回和回滚材料在私有运维位置。后续提交只同步验收和架构生命周期说明，最终交付核对全部 19 个运行包源文件与 HEAD 一致。
