## 测试设计

- 真实可解码 3840×2160 JPEG 生成独立 640×360、1920×1080 JPEG；原图逐字节保留，缩略图字节显著减小，不放大小图。
- HTML、结构完整但不可解码 JPEG、过大输入/像素、损坏存储被拒绝；输出不成为可用图片；并发受限，失败不覆盖原索引。
- 月浏览不触发第三方网络；未导入与缺失图片有明确反馈；同 ID 合并保留来源和本地媒体状态，ID 变化不复用旧图。
- 缩略图 URL、预览 URL、原图下载 URL 分离，只有视野内两张缩略图可并发，切月/切图后迟到结果不覆盖。
- 导入断点续跑、双来源缺档/部分失败、原图失败保留元数据、重复采集不丢历史；Actions 来源仅 Bing，数据分支不保存凭据。
- 本地服务重启后在上游断网情况下仍可读已导入月份及三种图片；端点拒绝未知 size、路径/URL 注入和未索引 ID。
- 真实旧图抽查、月度导入完整性统计、桌面和窄屏实际网络传输，单独于替身测试记录。

## 执行证据

本地 macOS / Node 24.21.0：`npm run check`（13 个运行/工具脚本）与 `npm test`（111/111）通过；`python -X utf8 tools/verify_research.py` 检查 238 份研究文件及 432 个引用通过，项目治理校验、差异空白检查通过。新测试先失败：缺少媒体模块、本地浏览仍访问来源、前端请求原图；实现后通过。补充宽幅全景用例先发现原有最小高度规则错误地作用于缩略图，改用解码器输出尺寸后通过。

一次全量测试发现错误状态异步落盘未被等待，导致临时目录清理冲突；已让归档失败和后台错误回调等待状态写入，后续全量测试通过。没有跳过或删除失败断言。

真实浏览器使用 ego-browser。桌面 1200 宽与手机 390×844：2018-09 / 2018-10 切换成功，无横向溢出。2018-10 的 31 张列表在首屏只请求当前预览，尚未进入视野的缩略图为 0 请求；滚动后逐步加载，未浏览的项保持未请求。原图仅点击下载时请求。2018-09-30 样本：缩略图 640×360 / 40,845 字节，预览 1920×1080 / 360,145 字节，下载 3840×2160 / 622,201 字节；下载 SHA-256 `aa56f764746ef81acc415c521148b20ef7e1f316114fd6f8c224c71d3ed514bf`。这些是本机真实路径证据，不作为公网耗时或全部图片的保证。

初次索引扫描两个月被来源中尺寸链接的 ID 冲突挡住：2024-01-26、2026-07-08。工具把歧义记录隔离后保留其余有效记录；2026-07-08 可由另一个来源补齐，2024-01-26 保留为缺档。完整导入共有 98 个月、2,962 条记录，图片保存与逐项检查仍在进行。部署、Actions 实际运行及最终图库统计待下方追加，当前不代表已上线。
