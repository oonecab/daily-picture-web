# 问题 019：自有历史图库与真正缩略图

- 状态：`closed`
- 日期：2026-10-21 Asia/Shanghai；重要变更（持久化、API、技术依赖、外部写入、发布）
- 计划：[015](../plans/015-owned-history.md)；测试：[自有图库](../docs/testing/owned-history.md)；里程碑：[015](../milestones/015-owned-history.md)

用户授权从两个现有归档一次性导入历史数据并保留署名，之后维护自己的索引和图片，新增索引由 GitHub Actions 从 Bing 获取。优先解决历史缩略图传输原图及按需加载，完成可用性检查和测试。

采用独立持久图片目录、640 像素缩略图、1920 像素预览和原始 JPEG。图片经 Sharp 完整解码后发布；磁盘文件摘要和清单关联同一日期与图片 ID。导入工具显式访问第三方，网页浏览只读自有索引/媒体。后台同步本仓库 codex/wallpaper-data 分支的每日索引，并保存新增图片。Actions 只需当前仓库 contents:write，不持有服务器凭据。

文档影响：TECH、治理清单、README、第三方声明、历史规则/契约、架构、环境/发布和测试基线。增加 Sharp 锁定依赖及 npm ci 安装步骤。保留已有月度 schema、收藏和原始索引；新增存储不随缓存淘汰。发布保留旧版本和数据备份，回滚不删除新图库。

1.4.0 已于 2026-10-21 发布，运行提交 `e6132ebdf434bf6986ee3e7ee2c3b2350c18fb9b`。98 个月共 2,962 张图片及 8,886 个媒体文件已保存并逐项核对摘要，原有 285 条记录完整保留。本机和目标 Linux 均通过 113 项测试；两次 Actions 实际采集成功，线上从自有分支同步并保存近期 15 张图片成功。公网历史浏览、原图下载与手机页脚验收见[测试记录](../docs/testing/owned-history.md)。

已知数据缺口：2024-01-26 的来源尺寸链接指向不同图片 ID，隔离后未导入；2026-07-08 的同类冲突由另一归档补齐。两个来源声明保留。定时计划已配置，未来调度的持续运行不由本次推送触发的成功结果推断。发布保留上个版本和原图库，可独立回滚。
