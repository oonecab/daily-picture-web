# 计划 017：修复历史同步与读取边界

- 状态：`in_progress`；负责人：项目维护者 / Codex
- 关联：[问题 021](../issues/021-history-reliability.md)、[验收](../docs/testing/history-reliability.md)、[里程碑 017](../milestones/017-history-reliability.md)

1. 固化旧快照、窗口外失败图片和重复缓冲区的失败回归。
2. 合并时比较版本时刻并保留同 ID 图片状态；后台从持久月索引恢复有界待补批次，状态包含尚未补齐总数。
3. 合并相同读取，为不同读取设置字节、并发、等待和消费者上限；HTTP 持有预算直至发送完成或连接关闭，验证超限及中断恢复。
4. 更新权威规则，运行登记检查与隔离慢客户端实验；审查、提交推送，保留旧发布和索引备份后部署，验证历史浏览、下载和后台同步。

发现回归时停止发布并修复；上线失败切回旧版本，保持图库及备份。实测记录区分本地容量与公网正常访问。
